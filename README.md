## Ink Cost calculator
we all know print shops in general charge flat rates per sheet for any type of a print out. meaning if two people went to a print shop with two different PDFs in hand, and they all want the print out in color, 
the shop will charge the same for both of them for a print out paper each, it should nor be like that, shop should be able to dynamically calculate ink cost per PDF and them charge appropriately.

this software solves excatly that probleme for all of us, now print shops do not need to guess prices and charge flat rates, if charged by flat rates at some point shop is going to loos money and also most of the time customer is going to pay more than what it was worth.
